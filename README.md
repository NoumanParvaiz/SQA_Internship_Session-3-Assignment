# Session 3 Automation Assignment

## Project Overview

This repository contains the automation testing tasks completed during Session 3 of the SQA Internship Program. The assignment covers web automation, API testing, and automation frameworks using different tools and technologies.

## Tools Used

- Playwright
- Cypress
- Selenium
- Robot Framework
- Postman

## Repository Structure

```text
Week 3 Session 3/
│
├── playwright/
├── cypress/
├── selenium/
├── robot-framework/
├── postman/
├── reports/
│   └── Session_3_Final_Report.pdf
│
└── README.md
```

## Task Summary

### Task 1 – Playwright Web Automation
- Automated 5 test scenarios
- Title verification and page navigation
- Form validation with valid and invalid inputs
- UI element verification
- Cross-browser testing
- HTML report generation
- Page Object Model (POM) implementation

### Task 2 – Cypress Automation
- Automated web scenarios
- Positive and negative assertions
- Test hooks implementation
- Screenshots and videos captured

### Task 3 – Selenium and Robot Framework
- Selenium test automation scenarios
- Robot Framework automation script
- Framework comparison and analysis

### Task 4 – Postman API Automation
- API requests using GET, POST, PUT, PATCH, and DELETE
- Positive and negative test cases
- Status code and response validation
- Environment variables usage

## Run Commands

### Playwright
```bash
npx playwright test
```

### Cypress
```bash
npx cypress open
```

### Selenium
```bash
python test.py
```

### Robot Framework
```bash
robot tests.robot
```

## Documentation

Detailed documentation, screenshots, AI prompts, learning outcomes, and challenges faced are included in:

reports/Session_3_Final_Report.pdf
```
